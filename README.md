# Plataforma de Economia Circular e Descarte Inteligente

Aplicação web focada em reutilização, reciclagem e negociação de itens usados.

## 🚀 Tecnologias
- HTML5 Semântico
- CSS3 (Variáveis, Flexbox, Grid)
- JavaScript (Vanilla JS ES6+)
- Bootstrap 5 (CSS/Componentes)

## 🎨 Design System (Cores)
- Azul Marinho: Confiabilidade
- Laranja: Ação, Energia, Destaque
- Branco e Cinza: Limpeza, Organização e Fundo

## 📁 Arquitetura
Arquitetura modular sem uso de frameworks, focada em LocalStorage para persistência de dados.
